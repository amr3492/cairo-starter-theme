Cairo Starter

A lightweight business/portfolio WordPress theme written from scratch: no frameworks, no page-builder lock-in, no jQuery.

Get the theme on GitHub

Features

  • Front page that sells out of the box - hero with editable heading/subheading/button, a services grid (pages using the Service template appear automatically), a recent-work portfolio grid, and a contact call-to-action.
  • Customizer-first - accent color (injected as a CSS variable) and all hero copy under Appearance > Customize.
  • Full template set - front-page, index, single, page, archive, search, 404, comments, plus a Service page template and reusable template parts.
  • Registered areas - primary + footer menus, one blog sidebar, three footer widget columns.
  • Modern WP support - custom logo, post thumbnails, HTML5 markup, responsive embeds, wide alignments, translation-ready, skip-link and ARIA-labelled navigation.
  • Responsive - CSS-grid layouts collapse cleanly; mobile menu toggle is 20 lines of vanilla JS.
  • Core classes covered - alignment, captions, sticky posts, galleries, pagination.

Install

1. Download or clone the repo.
2. Zip the folder (or upload it directly) under Appearance > Themes > Add New > Upload Theme.
3. Activate "Cairo Starter".
4. Set a static front page under Settings > Reading.
5. Create up to three pages with the Service template - they show in the front-page grid automatically.
